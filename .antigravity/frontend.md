# Documentación Frontend

## Stack Tecnológico
- React + Vite.
- TailwindCSS.
- Axios para peticiones HTTP.
- Framer Motion para animaciones suaves.

## Ejecución
1. Entrar en la carpeta `frontend/`.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.

## Organización de Componentes
- `src/components/ui`: Componentes base (Botones, Inputs).
- `src/components/cards`: Componentes de cartas de jugadores.
- `src/pages`: Páginas completas (Home, PackOpener, etc.).
- `src/services`: Servicios para llamadas al backend (API).
- `src/hooks`: Lógica de estado reutilizable.

## Estilo Visual
Inspirado en EA Sports FC 2026:
- Colores oscuros con acentos neón/dorados.
- Tipografía moderna (Inter/Roboto).
- Efectos de cristal (glassmorphism).
- Animaciones de apertura de sobres potentes.
